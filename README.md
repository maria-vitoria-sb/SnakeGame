# 🐍 Jogo Snake em Python (Pygame)

Este projeto é uma recriação do clássico **Snake Game**, desenvolvido em **Python** utilizando a biblioteca **Pygame**.  
O diferencial do jogo está no **sistema de fases dinâmicas**, onde as cores do cenário, da cobra e da comida mudam conforme a pontuação do jogador, além de possuir **tela de vitória e derrota**.

---

## 🎮 Funcionalidades

- Movimento clássico da cobrinha
- Geração aleatória de comida
- Crescimento da cobra ao comer
- Sistema de pontuação em tempo real
- **4 fases visuais diferentes**, alteradas conforme a pontuação:
  - Verde (início)
  - Azul
  - Rosa
  - Amarelo (fase final)
- Detecção de colisão:
  - Com as bordas da tela
  - Com o próprio corpo
- Tela de **Game Over** com opção de reinício
- Tela de **Vitória** ao atingir 20 pontos

---

## ⌨️ Controles

- **Setas do teclado** ou **W A S D**
  - ↑ / W — mover para cima  
  - ↓ / S — mover para baixo  
  - ← / A — mover para a esquerda  
  - → / D — mover para a direita  

- **ENTER** — reiniciar o jogo após perder ou vencer
